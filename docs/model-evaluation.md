# 新模型评测与发布默认流程

## 当前默认题集（2026-11-06，creative-suite-v6）

新批次默认 `--profile creator`，覆盖复古掌机分层拆解、Web3D 动态海底洗衣店、三操作小网页、数据图表和两图找不同。具体题目从 `scripts/evaluation/creation-suite.mjs` 共享读取。[v6 题集与交付规则](evaluation-suite-v6.md)

创作优先使用 `tokrace-claude-eval` 的 `prepare-creation.mjs` 和 `run.mjs` 持久原生会话；用户指定当前 harness 时遵循其选择。模型与工具条件据实记录：同环境换模型和各厂商原生产品分开归因。接口/身份/凭据从维护配置核实，不静默换路由或改全局设置，作品进程保持隔离。

允许作者自主运行、看图和修错，先低清预览再终稿；不沿用历史控制器请求/token/总时长预算，也不为满分无限打磨。首次自主交付后冻结源码、作品、工程、哈希及实际用量，失败或缺项照实保留。协调者追加提示后的补交/修订另列“追加反馈版”，附指令与用量，不覆盖首轮。网络/过载退避后可无反馈恢复原阶段；鉴权、余额、模型身份问题先解决实际原因。协调者统一录屏/编码不等于替作者改作品。

自动核验能否运行/打开、题目关键尺寸/数值、固定网页操作、媒体与必要事实及安全；查看实际图像和动画，不以退出或文件存在代替验收。AI 每题最多写三条可核对事实或关键缺项，附截图文件/区域或视频时间点；详细诊断可私有归档。默认不写工程长评、不打主观分、不作模型总排名。博主评语初始“待点评”，收到用户意见后整理和润色，新增事实须有证据。自动检查、作者自查、AI 观察与博主评价分别标明。

本地先交作品、关键事实、实际条件/用量和待填评语；需要时做同题、同画幅、同播放区间的上下对比视频。未知用量保持未知；墙钟可能含停等和渲染，不当作纯推理速度，也不推算没有独立计时的点评占比。

新任务默认本地草稿。只有本任务明确要求发布，或已有明确覆盖该任务的发布授权时，才执行现有双语、SEO、资产哈希、测试构建和正式页面验证流程；已有特定发布授权不扩大到新任务。公开包不含来源全文、隐藏思考或密钥。

## 显式旧题集与历史批次（v4）

`--profile standard|quick|extended` 仍按 [v4 规则](evaluation-suite-v4.md) 选择：标准11题、quick 10题、extended 14题。仅所选知识视频需要同一上海日期的锁定主题、资料和口播技能；旧批次恢复沿用原题、原协议，成功历史作品与哈希不改。不同协议/任务不混作同条件排名。下文直接 API 基线与旧 SVG/页面说明用于维护历史或显式选择的任务，不是 v5 的默认题量、点评或停止条件。

## 来源和模型身份

- 先核实厂商发布页、API 文档、模型名称、版本、发布时间、能力和价格。别名或匿名测试名需附来源；不能把传闻写成确认关系。
- 可变 API alias 不能作为固定 checkpoint 的证明。保存请求模型、返回模型、调用日期和官方版本映射来源。
- 保留已有评测数据与失败结果，新增批次使用独立文件。不同日期、模式和预算不要合并成通用排名。

## 历史 SVG 题集与 API 基线

本节用于旧 SVG 基线和显式选题。creator 的 SVG 题为数据图表，按上文核验和点评。旧静态题包括 9:41 钟表、数据图表和中文海报，动画为鹈鹕骑车。题目版本见 `scripts/evaluation/cases-v2.mjs` 的 `visual-svg-v2`，原 `cases.mjs` / `visual-svg-v1` 用于历史恢复。研究 thinking 档位时，核实厂商支持后另建可比较批次。

以下直接API请求的历史预算与记录规则用于维护已有基线，不是实际创作任务的停止条件。

每题每档保留首轮。SVG 生成或渲染失败时继续独立重试，直到得到可渲染结果；不覆盖失败、不择优挑选、不手动修复后冒充模型输出。记录每次请求、原因、参数、尝试序号及累计耗时；成功后仍须检查内容正确性。若需反馈修正，公开完整追加提示和对话。新请求默认温度 0（注明厂商是否忽略）、max_tokens 12288、600 秒超时；补测失败后可将预算提高到 32768，DeepSeek 连续截断时可提高至 65536，页面明确预算变化，不能称为同预算首轮比较。服务端过载采用至少 60 秒退避，鉴权、余额或限流阻塞应如实报告。单次 runner 保持不可覆盖，重试用新的编号证据目录。

这是 **SVG 代码绘图**；只有实际调用图像模型原生 API 才能写“原生图像生成”。不得用其他图像生成工具替代被评测模型的输出。

## 可复用命令

复制 `scripts/evaluation/deepseek-1017.json` 并修改模型、官方 endpoint、环境变量名称、模式和版本来源。配置和证据不得写入密钥。`extraBody` 只放厂商要求的非敏感扩展参数，不覆盖固定 model/messages/token/stream 字段。

```sh
node scripts/evaluation/run.mjs scripts/evaluation/MODEL.json output/MODEL-visual/evidence.json
python3 scripts/evaluation/extract.py output/MODEL-visual/evidence.json MODEL-SLUG
node scripts/evaluation/render.mjs output/MODEL-visual/extracted.json output/MODEL-visual/rendered.json
```

runner 在发请求前记录槽位，续跑跳过所有已记录请求，并拒绝不同配置或提示词混入同一文件。断电可能留下 `interrupted`；保留并说明，不覆盖记录。首次配置使用新的输出路径。

动画题 **鹈鹕骑车动画**：固定提示词要求 4 秒循环、轮辐和脚踏转动、腿部连接、主体不出画布。被测模型生成 SMIL，不能由其他模型或人工给静态图补动画。验证后用隔离 Chromium 禁用网络，固定 0–3.9 秒每 0.1 秒截图，导出 40 帧 WebP。检查帧间确实变化、全部动图的代表帧与播放效果，并检查首尾衔接。页面提供播放/暂停、原始 SVG、动图下载和逐图点评，默认静止。

提取器保留首个完整 SVG 原字节，只去掉外围说明或代码围栏。XML 校验拒绝脚本、外部资源和主动内容；不修复模型代码。sharp 将其渲染为 1200px PNG。页面使用 PNG / 编码后的动图，不向站点 DOM 注入模型 SVG；只有动画任务允许受限 SMIL 标签，静态任务仍拒绝动画。渲染失败也要保存原因。

逐张查看成图，包括中文字体；按所选题核对关键数值和指定文字。区分自动检查、AI 观察与博主评价，不称为独立人工评分。v5 每题只保留最多三条有证据的事实或缺项，主观点评待用户提供，不以“可渲染”替代内容核验。

## 明确要求发布时的页面

本节仅在执行发布任务时使用；不因此自动抓取官方图或制作长报告。v5 的博主主观点评仍待用户提供。

- 页面采用“模型介绍与发布背景 → 官方标识 → 测试范围与概括性结论 → 作品结果”的顺序。先让读者了解模型，再进入具体案例；总评不以尚未介绍的作品名称开头。
- 主文只保留简明结论与具体观察，删除重复总结、未来测试清单和反复自证的说明。公开详情提供必要的作品、源码、运行条件和脱敏用量；完整过程记录留在批次档案。来源和必要条件放在相关图表或数据旁，避免每段重复。
- 结果按任务分组，便于并排查看不同档位；创作评测按所选任务类别分组。侧栏目录使用少量清楚的入口，中英文同步。仅调整内容与排版时保留原始数据、历史测试日期和资产，不发起新的模型请求。
- 从对应版本的官方原文下载 benchmark 原图，保留轴、图例、脚注和原始字节。保存来源页、图片 URL、日期、尺寸、SHA-256 和版权方。
- 仅有旧版本图时明确版本范围；找不到对应图则说明，不用自行绘制的图冒充官方原图。官方展示案例也不能冒充本站实测。
- 官方成绩与本站实测分区展示，标明未独立复现及框架、Pass@k、成本口径等限制。
- 使用 `components/VisualEvaluation.tsx`；通过 `display` 配置厂商、模式名称、历史请求数量、方法和官方图说明。旧 SVG 基线按模式并排，手机端单列；提供原始提示词、SVG/PNG、大图、脱敏 JSON 证据与实际时间/token。v5 按新题集展示作品、关键事实与博主评语，不为兼容组件添加未选择的题目。
- 新视觉记录存放 `public/evaluations/MODEL-SLUG-visual.json`，素材位于 `public/evaluations/MODEL-SLUG/assets/`。保留旧文本/代码数据。JSON 仅含正文和思考耗时/计数，不发布隐藏思维链。
- 中英文页面同步：标题、description、自然关键词、图片 alt、来源、内部链接、canonical、hreflang、TechArticle 图片和 dateModified、sitemap 更新时间。保留原始 datePublished 和历史实测日期。

## 验证与交付

运行有意义的证据校验（原 SVG 字节、PNG 哈希/尺寸、完整首轮记录、官方图来源）及仓库测试和 build。查看桌面和 390px 页面：无横向溢出、图片加载、文字清楚、大图可打开；回归使用共用组件的其他评测页。

用户要求发布时沿用当前项目已确认的部署流程，检查实际服务映射再部署。发布后在 canonical 域名验证中英文页面、HTML/JSON-LD、sitemap、所有新资产字节、浏览器图片加载与手机布局。记录部署 ID 和证据。IndexNow 被接受不等于已被收录。最终明确已达到本地、预览或公开发布的哪一步。

可扩展但不能写成已实测的项目：旋转六边形弹球、截图复刻网页、太阳系动画、六图标一致性、多模态读图表。动画须录制固定时长并查物理/轨迹，网页须比较 390/1440px 截图，多模态须保存输入图和原回答。

## 2026-10-21 补测命令

`scripts/evaluation/upgrade.mjs deepseek|minimax|longcat` 创建独立重试与档位补测批次；`scripts/evaluation/animate.mjs RESULT_JSON` 为已验证的 SMIL 输出创建 4 秒 WebP。原始首轮 JSON 保持不变，新页面数据和全部补测记录放入 `MODEL-SLUG-supplement.json`。每个新模型需按当前官方文档配置支持矩阵。

请求实现使用 Node 原生 HTTP(S) 流式读取，统一受已记录的 AbortSignal 超时控制，避免 fetch 另有 300 秒响应头超时。原请求不得因传输实现调整而删除；保留 transport/errorCode。网络失败与厂商 5xx 至少退避 60 秒，不能把它们计成 SVG 语法错误。超时实录可能因系统挂起而超过配置值，不用这些墙钟时间做模型速度排名。
