# TOKRACE 博主创作实测 v5

本页记录 2026-11-05 的 `creative-suite-v5` 历史题集。当前默认见 [v6 题集](evaluation-suite-v6.md)。恢复 v5 批次时读取其冻结题目、原协议和成功作品。

## 五题与交付

| ID | 任务 | 主要交付与核验 |
| --- | --- | --- |
| `bookshelf` | 轻量 Blender 书架 | 宽800、深300、高1200毫米，板厚18毫米，三个等净高格；第二版仅将宽改为1000毫米，格数不变。两张图、原生工程和重建脚本，检查关键尺寸/分格；不要求UV、LOD或视频。 |
| `creator-web3d` | Web3D 动态海底洗衣店 | `index.html` 与源码；允许 Three.js 等框架，由作者选择实现。实际三维场景与运动按题目检查，协调者按统一视口/时间区间录屏。 |
| `creator-webapp` | 三操作小网页 | 可运行网页与源码；按冻结题目完成三个指定操作，截图/录屏保留操作结果，不能只展示静态外观。 |
| `svg-dashboard` | 数据图表 | 原始SVG与渲染图；对照题目数据核对关键数值、文字和图形关系。代码绘图不称原生图像生成。 |
| `creator-vision` | 图片理解 | 保存原输入图片、原题和原回答；依据预先冻结的事实核对正确、错误及未回答项，不把自报信心当正确性。 |

题目和完整规格以 `scripts/evaluation/creation-suite.mjs` 及其引用定义为准。各模型共用冻结的提示词、输入和关键检查，独立创作；不共享其他模型的答案或工程，不调用其他生成模型代做。记录 suiteVersion、profile、每题规格/输入哈希、模型/版本/路由、harness 与实际工具条件。框架依赖与外部生成资产分开，不能借引入依赖替换作者作品。

creator 不包含四支知识视频，不要求为本轮检索日更选题、生成 TTS 或准备知识视频讲稿。显式选择 v4 知识视频时执行 [v4 规则](evaluation-suite-v4.md)，同日复用锁定题目与来源；不混作 v5 同条件排名。

## 首次交付与追加版

允许作者在自主会话内运行、看图和修错，先预览后终稿，不追求所有检查满分。首次自主交付后立即冻结源码、工程、作品、哈希和实际用量，失败或缺项也保留。协调者的追加反馈和后续补交从该快照派生为“追加反馈版”，不覆盖首次交付，不只展示最好一次。网络/服务中断后的无反馈恢复仍属于原阶段；不能把作品错误混作基础设施故障。只差统一录屏或编码时执行作者已有代码，不再要求其挑镜头或润色。

不沿用历史控制器请求/token/总时长预算；模型退出、文件存在、可打开和内容正确分别记录。追加反馈版附追加指令和用量，原始首轮/失败快照保留。协调者可统一录屏和编码，但不替作者修内容后计入其成绩。

## 自动核验与博主点评

自动技术核验只覆盖交付可运行/打开、关键尺寸或数值、固定操作、媒体解码，以及题目必要事实与安全。实际查看图像和动画；Blender 工程用 `--disable-autoexec` 重开，生成的 SVG/网页沿用现有隔离与主动内容校验。技术通过不代表审美、事实和功能都通过。

AI 每题最多写三条可核对的关键事实或缺项，附截图文件、图片区域或视频时间点；原始诊断可归档。默认取消 AI 主观分数、模型总排名和工程长评，不为填满检查矩阵反复检查。博主评语初始为“待点评”；收到用户意见后整理和润色其判断，新增事实须有证据，不替用户编造偏好。自动检查、作者自查、AI 观察与博主评价明确区分。可确定的事实写清依据，不能确定就列待确认，不把推测写成实测。可用“实测表现 → 我的看法 → 适合什么用途”的三句评语结构。

## 同题展示与时间口径

先交本地作品与事实，再按需要用同题同画幅、同播放区间拼成上下对比视频；模型与 harness 标签清楚，不裁掉关键失败、不替静态作品补动画。统一截图/录屏设置，保留原始输出与展示衍生物的关系。

相同 harness 换模型时讨论该条件下的模型表现；各家原生应用比较讨论产品系统。不同任务、输入、版本、harness 或追加反馈阶段的结果，不能拼成同条件总排名。小样本用于案例点评；需要声称稳定差异时，再在相同条件下独立复测。

记录能取得的真实请求数、token、费用和时间；未暴露保持未知。墙钟时间可能含网络、停等和渲染，不等于纯模型推理时间；并发任务的单题耗时不能相加冒充总耗时。技术核验/点评未单独计时就不推算其占比，不承诺未经测量的省时比例。

## 本地草稿与发布

新任务默认本地草稿。仅本任务明确要求发布，或已有明确覆盖该任务的发布授权时，才执行现有发布流程；已有特定授权不扩大到新任务。本地先交作品、至多三条事实、运行条件/用量、待填人评；不默认为了发布准备双语长报告、官方跑分图库或部署。确有引用的厂商数字仍需注明来源并与实测区分。

发布时执行仓库现有双语、SEO、不可变资产/哈希、测试构建和正式页面/手机播放验证流程。来源全文、隐藏思考、密钥及私有日志不进入公开包。最终明确本地、预览与正式发布的实际状态。
